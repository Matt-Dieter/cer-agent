# Agent CER -> Moodle

Rédige les CER de prosit (skill cer-prosit) et les dépose sur le Moodle de l'Ucac-Icam.

- `AGENT.md` : consignes de la tâche planifiée
- `moodle_depot.py` : dépôt sur Moodle par navigateur automatisé (Playwright)

Identifiants lus dans `MOODLE_URL`, `MOODLE_USER`, `MOODLE_PASSWORD` (variables d'environnement, jamais dans le dépôt).
